Budget Master 9000 - Portable
=============================

1. Keep bm9000.portable next to BudgetMaster9000.exe
2. Double-click BudgetMaster9000.exe
3. Your database is bm9000.db in this folder

This portable package is built from the same source as the installers
in release\installers\ so features stay in sync.

Rebuild everything:
  npm run release
  powershell -File scripts\stage-release.ps1
