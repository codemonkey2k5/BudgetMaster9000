# Security

Budget Master 9000 is a **local desktop app**. Your data stays on your machine.

Optional **App Lock** uses a passphrase to stop casual snooping on a shared PC. It is not a substitute for BitLocker, a strong Windows sign-in, or careful handling of exported backups.

There is no cloud recovery for a forgotten App Lock passphrase. Export backups and store them safely.

To report a security issue privately, use a GitHub security advisory on this repository.
